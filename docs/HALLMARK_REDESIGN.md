# sepol HALLMARK UI 재디자인

2026-10-29. 사용자 지정: 따뜻한 종이색과 짙은 녹색의 차분한 편집형.

- app scope / full redesign. 폰트는 기존 Pretendard 본문, Georgia·Batang 제목 체계.
- 카드 그리드를 구분선 중심 정책 인덱스로 변경. 동네 설정·검색·정책 근거의 위계 강화.
- 기존 경로·API·필드·이벤트 훅 유지. 데이터·DB·게임·DNS 변경 없음.
- 정책 제목은 모바일에서 한 줄 말줄임되지만 DOM의 전체 제목과 상세 보기는 유지.
- Floor 0 FAIL / Reflex 0. 실제 URL 렌더 검사 완료. 남은 2 WARN은 정적 HTML 캡처를 같은 런에서 비교하지 못한 기록상의 한계.
- Finish F7: 필드는 공통 레시피, 정책은 구분선, 폼은 색면, 출처는 열린 목록으로 구분.
- 독립 검토: ship. 정책 인덱스의 데스크톱·모바일 화면 검토, 다른 화면은 기능·반응형 검사로 확인.
- 19개 단위 테스트, 빌드, 6화면×4폭 UI 검사와 모의 위치 흐름 통과.
- 실제 변경 전 비교는 기존 운영 화면 캡처를 사용. file:// 정적 셸 이미지는 유효한 비교 화면으로 사용하지 않음.
- HALLMARK 생성 캡처는 public/.assetsignore로 배포 제외.

문구 변경: ‘정책의 근거를 읽고, 변화가 닿는 곳을 봅니다.’ → ‘우리 동네 정책을 근거부터 살펴보세요.’. 설명용 상단 소제목을 제거하고 제목에 의미를 통합. 권한·개인정보·동의 문구의 의미는 유지.
