# 실행 검증

2026-10-29, Node.js 24.19.0, Wrangler 4.92.0, Chromium 154의 현재 클라우드 인스턴스에서 실행했다.

| 검사 | 확인한 결과 |
| --- | --- |
| `npm test` | 12개 통과. 한국어 분류, 소수 의견의 높은 영향 반영, 가중치와 동점 처리, 예산 한도, 입력 검증, 경로 분리, 오류 응답 |
| `npm run build` | Worker와 로컬 정적 파일의 배포 dry-run 통과 |
| `npm run db:local` | 독립 로컬 D1 초기화, 재실행 시 추가 migration 없이 종료 |
| `npm run test:ui` | 가중치·예산·검색·계산 근거·빈 목록·접수·이스케이프·오프라인 복구 확인 |
| 실제 DB 작성 | 로컬 API 201 응답, DB 조회로 새 의견 확인, 같은 접수 ID 재시도는 중복 저장 없이 200 응답 |
| 화면 크기 | 375/390/768/1280px에서 6개 화면, 총 24개 조건의 문서 가로 넘침 없음 |
| 내보내기 | 실제 CSV 다운로드 파일의 제목·자료 구분·비용 열 확인, 인쇄용 PDF 생성 |
| 계산 표시 | 11,200만 원이 반올림 손실 없이 1.12억 원으로 표시되는지 확인 |
| 아이콘 | Lucide 43개 symbol의 유효한 XML 구조와 브라우저의 실제 표시 확인 |
| Hallmark | app scope, 정적 코드와 실제 브라우저 검사. Floor 0 FAIL, Reflex 0, 미해결 경고 0 |

Hallmark의 최종 결과 요약은 `design-check.json`에 보존했다.
중립 버튼 스타일과 서로 다른 작업 화면의 데이터 패널에 관한 Finish 두 항목은
근거를 기록해 답변했다. 시각 검토는 같은 대화에서 수행했으며 독립 검토자라고 주장하지 않는다.

UI 검증이 만든 의견은 **로컬 DB에서 해당 UUID 행만 삭제**했다.
실제 시민 데이터나 원격 DB를 검증 대상으로 사용하지 않았다.
원시 화면 캡처와 PDF는 Git에서 제외한 `artifacts/`에 있다.

## 검증하지 못한 범위

Cloudflare 토큰이 현재 실행 환경에 없고, 도메인/API 네트워크 허용 설정은 초안에만 있다.
따라서 실제 `ageclan.com/app` 배포, 원격 D1 생성, DNS 프록시 전환, 운영 게임의 접속은 검증하지 못했다.
로컬 성공이나 GitHub 저장이 실제 도메인 공개를 의미하지 않는다.
원격 배포 시에는 독립 DB와 기존 DNS·경로 호환성을 먼저 확인해야 한다.
